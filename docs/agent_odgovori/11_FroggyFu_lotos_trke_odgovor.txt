### `FroggyFu::PickNormalCandidatesForAttempt(logic, normalCandidates, amount, highScoreRatioPercent)` `[KOD: 0x5ec5f4c]`
```csharp
List<Point> PickNormalCandidatesForAttempt(
    GameLogic logic, List<Point> normalCandidates, int amount, int highScoreRatioPercent)
{
    if (amount < 1 || normalCandidates.Count == 0)
        return new List<Point>();                               // [KOD: 0x5ec6068-0x5ec6084]

    int ratio = Math.Max(0, Math.Min(100, highScoreRatioPercent)); // [KOD: 0x5ec60a0-0x5ec60bc]
    int pickCount = Math.Min(amount, normalCandidates.Count);      // [KOD: 0x5ec60d0]
    var pool = new List<Point>(normalCandidates);                  // [KOD: 0x5ec60f8]
    var weights = new List<int>(pool.Count);
    long totalWeight = 0;

    foreach (Point p in pool) {
        SlotModel s = logic.boardModel[p];                      // [KOD: 0x5ec6198]
        int tier = Math.Min((int)s.ScoreTier_1c, 5);            // [KOD: 0x5ec61a4-0x5ec61c4]
        int w = 100 + (tier - 1) * ratio;                       // [KOD: 0x5ec61f0]
        weights.Add(w);
        totalWeight += w;                                       // [KOD: 0x5ec6228]
    }

    var result = new List<Point>(pickCount);
    for (int i = 0; i < pickCount && totalWeight > 0 && pool.Count > 0; i++) {
        // RNG #1..pickCount:
        int roll = logic.randomWrapper.Next((int)totalWeight);  // [KOD: 0x5ec62e0]
        int cum = 0, chosen = pool.Count - 1;
        for (int j = 0; j < pool.Count; j++) {
            cum += weights[j];                                  // [KOD: 0x5ec630c-0x5ec6310]
            if (cum > roll) { chosen = j; break; }              // [KOD: 0x5ec6314-0x5ec6318]
        }
        result.Add(pool[chosen]);                               // [KOD: 0x5ec6348]
        int w = weights[chosen];                                // [KOD: 0x5ec63bc]
        pool.RemoveAt(chosen);                                  // [KOD: 0x5ec63d8]
        weights.RemoveAt(chosen);                               // [KOD: 0x5ec63f0]
        totalWeight -= w;                                       // [KOD: 0x5ec6404]
    }
    return result;
}
```

### `FroggyFuEntranceAttemptEvaluator` (`PickBestAttempt`, `EvaluateAttempt`, `SimulateEntrance`, `CompareAttempts`, `SatisfiesPlacementMustHaves`)

- **Šta je "pokušaj" i koliko ih ima:** `allTargetSets` (`List<List<Point>>`) je lista kandidatskih skupova polja za eksploziju ulaza, koju pravi `BuildPlacementSelection` (nije u dump-u). `PickBestAttempt` `[KOD: 0x5ed1dd0]` prolazi redom `i = 0 .. allTargetSets.Count - 1`, poziva `EvaluateAttempt(..., attemptIndex = i + 1, ...)` `[KOD: 0x5ed1eb4, 0x5ed1ef0]` i drži najbolji po `CompareAttempts >= 1` `[KOD: 0x5ed1f84-0x5ed1f90]`.

```csharp

    bool requireEnergyMatch, int minimumPiecesToPull, bool enforceSkipSameRequirement,
    SlotColor energyColor, bool useScoreTargeting, int calculatedScoreTarget,
    Func<GameLogic, bool, bool, PlacementSelection> placementSelectionFactory,
    Func<GameLogic, int> getSpecialsLeftScore,
    Func<BoardModel, ComboModel, Point, Point, SlotColor> getComboColorFromUnswappedBoard,
    int playerScore)
{

    SimulateEntrance(logicClone, explosionTargets);             // [KOD: 0x5ed2210]
    var sel = placementSelectionFactory(
        logicClone, requireEnergyMatch, enforceSkipSameRequirement); // [KOD: 0x5ed2238]

    var eval = new PlacementAttemptEvaluation {
        attemptIndex = attemptIndex,                            // [KOD: 0x5ed225c] (+0x10)
        explosionTargets = explosionTargets,                    // [KOD: 0x5ed2260] (+0x18)

        requireEnergyMatch = requireEnergyMatch,                // [KOD: 0x5ed226c] (+0x28)
        placedCount = sel.Positions.Count                       // [KOD: 0x5ed22dc] (+0x2c)
```

*Napomena za RNG u `EvaluateAttempt`:* `SimulateEntrance` na `logicClone` `[KOD: 0x5ed2210]` (i `DestroyMatches` na `scoreClone` `[KOD: 0x5ed25d0]`) troši RNG na **klonu** (`logicClone.randomWrapper`), tako da ne menja RNG glavnog toka `logic`, ali *jeste* deterministički vezan za RNG stanje pri ulasku u `PickBestAttempt`.
Inače, u `SimulateEntrance` `[KOD: 0x5ed29cc]`: pravi `ComboModel(10, explosionTargets, explosionTargets[0], 63)`, zove `logicClone.DestroyMatches`; ako nije aktiviran `onDestroyed` callback, zove `DamageSlots(explosionTargets, logicClone, true)` -> `DropSlotsDown()` -> `RefillSlots(logicClone, false)` `[KOD: 0x5ed2c3c-0x5ed2c74]`.

- **Redosled kriterijuma u `CompareAttempts(candidate, currentBest, ...)` `[KOD: 0x5ed2f88]`** (vraća `> 0` kad je `candidate` bolji):
  1. `candidate.placedCount - currentBest.placedCount` (više postavljenih lotosa pobeđuje) `[KOD: 0x5ed2f94]`
  2. `candidate.adjMatchCount - currentBest.adjMatchCount` (više lotosa pored spojeva pobeđuje) `[KOD: 0x5ed2fa4]`
  3. Ako `enforceSkipSameRequirement`: `candidate.distinctColorCount - currentBest.distinctColorCount` (više različitih boja ispod lotosa) `[KOD: 0x5ed2fc0]`
  4. Ako `requireEnergyMatch`:
     - `candidate.adjEnergyCount - currentBest.adjEnergyCount` `[KOD: 0x5ed2fd4]`
     - `CompareBool(candidate.energySatisfied, currentBest.energySatisfied)` (`true > false`) `[KOD: 0x5ed2fe8]`
  5. `currentBest.separationDeficitSum - candidate.separationDeficitSum` (manji deficit razdvajanja pobeđuje) `[KOD: 0x5ed3010]`
  6. Ako `enforceMinPiecesRequirement` (`minimumPiecesToPull > 1`): `candidate.matchingReqColorCount - currentBest.matchingReqColorCount` `[KOD: 0x5ed3020]`
  7. Ako `useScoreTargeting`: `currentBest.scoreTargetDistance - candidate.scoreTargetDistance` (manja apsolutna razlika `|(newScore - playerScore) + specialsLeftScore - calculatedScoreTarget|` pobeđuje! Znak za `GetSpecialsLeftScore` je `+` uz `newScore`, težina `1`) `[KOD: 0x5ed3034-0x5ed3044]`
  8. Tie-breaker: `currentBest.attemptIndex - candidate.attemptIndex` (raniji pokušaj pobeđuje) `[KOD: 0x5ed3048]`.

- **Šta proverava `SatisfiesPlacementMustHaves(attempt, lotusCount)` `[KOD: 0x5ed299c]`:**
  `attempt != null && attempt.placedCount >= lotusCount && attempt.allAdjToMatches (+0x4d) && attempt.sepSatisfied (+0x50)` (gde je `sepSatisfied` = `separationDeficitSum == 0`).
  `PickBestAttempt` **ne poziva** `SatisfiesPlacementMustHaves` — uvek vraća najbolji pokušaj iz `CompareAttempts`. Šta se desi kad nijedan pokušaj ne zadovoljava `SatisfiesPlacementMustHaves` nalazi se u `FroggyFuLotusPlacementPlanner::BuildPlacementSelection` (`0x5b954f0`), koji nije priložen.

## 2. (A) Da li se broj lotosa po aktivaciji menja?

U `FroggyFu::PickLotusPositions` `[KOD: 0x5ec68a4-0x5ec68c0]`, broj lotosa (`w21`) računa `FroggyFu::GetValueForActivation(this._cfg48, this.ActivatesThisTurn)` (`0x5ec5e90`). Takođe `GetValueForActivation` se zove i za `this+0x68` i `this+0x70`, a u `ResolveNextPlan` i za `this+0x50` (`gatherRadius`).
Međutim, telo `FroggyFu::GetValueForActivation` (`0x5ec5e90`) i `FroggyFuLotusPlacementPlanner::BuildPlacementSelection` (`0x5b954f0`) **nisu priloženi** u isecima, pa se iz dostavljenog koda vidi da zavisi od `ActivatesThisTurn` (broja aktivacija u potezu), dok je eventualno smanjenje zbog već postojećih lotosa na tabli ili pečuraka u `GetValueForActivation` / `BuildPlacementSelection` `[PRETPOSTAVKA — treba poslati 0x5ec5e90 i 0x5b954f0]`.

## 3. (B) `UnifiedFroggyFuAttractionPlanner::Pull` i `StampGatherRegion` (`b_attraction.txt`)

**Važno:** Ni `Pull` ni `StampGatherRegion` ni jedna njihova pomoćna metoda **NE troše RNG**! Sve je potpuno determinističko.

### `CalcBoardDistance` `[KOD: 0x5ed1498]` & `InGatherRegion` `[KOD: 0x5ecf390]`
- `dx = |p.x - lotus.x|`, `dy = |p.y - lotus.y|`
- `dist = chebyshev ? Math.Max(dx, dy) : (dx + dy)`
- `InGatherRegion = (dist <= radius)`

### `StampGatherRegion(AttractionStepParams p)` `[KOD: 0x5ecf450]`
1. Na tabli nalazi sva polja sa figurama koje zadovoljavaju `[KOD: 0x5ed1814]`: `slot.HasPiece_24 != 0 && slot.MatchesWithColor(p.dominantColor) && slot.Movable_25 != 0`.
2. Uklanja svako polje `pt` za koje važi `[KOD: 0x5ed185c]`:
   `p.allBlocked.Contains(pt) || p.secondaryCells.Contains(pt) || !InGatherRegion(p.lotusPos, pt, p.gatherRadius, p.gatherUsesChebyshev)`.
   (Dakle, obrađuje **isključivo** pokretne, neblokirane figure dominantne boje **unutar** oblasti skupljanja).
3. Za svako preostalo polje `pt`, ako `p.stampAction != null`, poziva `p.stampAction(p.logic, p.outConversions, pt, p.dominantColor)` `[KOD: 0x5ecf658-0x5ecf67c]`.
*(Napomena: samo telo delegata `stampAction` je u `FroggyFu::<ResolveNextPlan>b__...`, nije priloženo.)*

### `BuildPrioritizedTargets(...)` `[KOD: 0x5ed002c]`
```csharp
List<Point> BuildPrioritizedTargets(
    GameLogic logic, Point lotusPos, int maxRadius,
    HashSet<Point> alreadyPulled, HashSet<Point> allBlocked, HashSet<Point> avoidTargets)
{
    var list = new List<Point>();
    for (int dx = -maxRadius; dx <= maxRadius; dx++) {        // [KOD: 0x5ed0170-0x5ed02c4]
        for (int dy = -maxRadius; dy <= maxRadius; dy++) {
            if ((dx | dy) == 0) continue;                       // preskace sam lotos [KOD: 0x5ed0198]
            Point pt = new Point(lotusPos.x + dx, lotusPos.y + dy);
            if (!logic.boardModel.IsPointInBound(pt)) continue; // [KOD: 0x5ed01dc]
            if (logic.boardModel[pt].HasPiece_24 == 0) continue; // [KOD: 0x5ed01fc]
            if (alreadyPulled.Contains(pt)) continue;
            if (allBlocked.Contains(pt)) continue;
            if (avoidTargets != null && avoidTargets.Contains(pt)) continue;
            list.Add(pt);
        }
    }
    return list
        .OrderBy(t => Math.Abs(t.x - lotusPos.x) + Math.Abs(t.y - lotusPos.y))      // [KOD: 0x5ed1b78]
        .ThenBy(t => Math.Max(Math.Abs(t.x - lotusPos.x), Math.Abs(t.y - lotusPos.y))) // [KOD: 0x5ed1bf4]
        .ThenBy(t => t.x)                                                             // [KOD: 0x5ed16fc]
        .ThenBy(t => t.y)                                                             // [KOD: 0x5ed1704]
        .ToList();
}
```

### `BuildDominantCandidates(...)` `[KOD: 0x5ed0494]` & `FilterExplicitCandidates(...)` `[KOD: 0x5ed061c]`
- Ako je `explicitCandidates != null`: `FilterExplicitCandidates` prolazi kroz `explicitCandidates` redom i zadržava `pt` ako nije u `allBlocked`, `alreadyPulled`, `consumed`, unutar table je i `slot.HasPiece_24 != 0 && slot.Movable_25 != 0` `[KOD: 0x5ed0758-0x5ed07ec]`.

Dakle, uzima samo figure **IZVAN** oblasti skupljanja!

```csharp
        if (next == target) { bestNext = target; break; }       // [KOD: 0x5ed1160]
        if (!logic.boardModel.IsPointInBound(next)) continue;   // [KOD: 0x5ed1178]
        if (visited.Contains(next) || allBlocked.Contains(next)
            || alreadyPulled.Contains(next) || avoid.Contains(next)) continue; // [KOD: 0x5ed1194-0x5ed11f8]
        SlotModel slot = logic.boardModel[next];
        if (slot.HasPiece_24 == 0) continue;                    // [KOD: 0x5ed1214]

        int dist = Math.Abs(next.x - target.x) + Math.Abs(next.y - target.y); // [KOD: 0x5ed1234-0x5ed1270]
        // Izbegava gazenje preko figura iste dominantColor ako moze:
        int penalty = slot.MatchesWithColor(dominantColor) ? maxSteps : 0;    // [KOD: 0x5ed1274-0x5ed1288]
        int cost = dist + penalty;
        if (cost < bestCost) {
            bestCost = cost;
            bestNext = next;
        }
    }
    if (bestNext == Point.Invalid) break;                       // [KOD: 0x5ed130c]
    path.Add(bestNext);                                         // [KOD: 0x5ed1350]
    visited.Add(bestNext);                                      // [KOD: 0x5ed1384]
    cur = bestNext;
}
if (cur != target)
    return new List<Point> { source, target };                  // [KOD: 0x5ed138c-0x5ed1468] fallback direktan skok!
return path;
```

### `Pull(AttractionStepParams attractionParams)` `[KOD: 0x5ecf708]`
1. Ako je `explicitCandidates == null`, `avoidTargets = secondaryCells`, inače `null` `[KOD: 0x5ecf8e8]`.
2. `targets = BuildPrioritizedTargets(...)` `[KOD: 0x5ecf910]`.
3. Inicijalna lista kandidata: `FilterExplicitCandidates` ili `BuildDominantCandidates` `[KOD: 0x5ecf980 / 0x5ecf9dc]`.
   - Ako je `explicitCandidates == null`, sve kandidate sa `Manhattan(pt, lotusPos) == 1` uklanja iz `targets` i `candidates` i dodaje u `alreadyPulled` `[KOD: 0x5ecfa04-0x5ecfb40]`.
4. `maxPulls = initialCandidates.Count`.
5. Petlja (`pulled = 0 .. maxPulls - 1`, dok `targets.Count > 0`) `[KOD: 0x5ecfb50-0x5ecff94]`:
   - Ponovo računa kandidate (`FilterExplicitCandidates` ili `BuildDominantCandidates`), pa ih sortira `OrderPiecesOnion` `[KOD: 0x5ecfc4c]`. Ako je prazno, prekida.
   - `source = ordered[0]`.
   - `target = PickBestTarget(targets, source, lotusPos)` `[KOD: 0x5ecfca0]`, i uklanja `target` iz `targets` `[KOD: 0x5ecfcfc]`.
   - `path = BuildCascadePath(source, target, ...)` `[KOD: 0x5ecfce4]`.
   - Za svaki korak `i = 0 .. path.Count - 2` (`p0 = path[i], p1 = path[i+1]`):
     - Dodaje u `outConversions`: `ConvertSlotModel(board[p0], p1, 3)` i `ConvertSlotModel(board[p1], p0, 3)` `[KOD: 0x5ecfd6c, 0x5ecfe2c]`.
     - Poziva `logic.boardModel.Swap(p0, p1)` `[KOD: 0x5ecfec4]` — **polja izvan oblasti kroz koja prolazi putanja se zamenjuju (swap) korak-po-korak, gurajući prethodnu figuru na staro mesto privučene figure!** (Ako je putanja zaglavljena i vratila `[source, target]`, radi direktan swap `source <-> target`).
     - Beleži `moveRecorder.Record(p0, p1)` `[KOD: 0x5ecfef8]`.
   - Dodaje `target` u `alreadyPulled`; ako je `explicitCandidates != null && source != target`, dodaje `source` u `consumed` `[KOD: 0x5ecff24-0x5ecff80]`.

### `ComputeBlobSpecials` `[KOD: 0x5ecaee4]` — koji specijal nastaje i na kom polju
1. Poziva `BoardAnalyzer::GetAllCombos(logic, null, false, null, null)` na tabli **posle** povlačenja `[KOD: 0x5ecb358]`.
2. Za svaki `c` iz `allCombos`:

## 5. (C) Lotos pogođen eksplozijom (`c_lotus_hit.txt` i `IsActiveLotus`)

1. **`AnyMatchEnergyBoardAbility::IsActiveLotus(logic, froggyFu, p)` `[KOD: 0x5d911c8]`:**
   Vraća `true` ako i samo ako je na polju `p` `slot.SlotValue (+0x12) == 0x28` (**40**) **I** `froggyFu.LotusPositions.Contains(p)`. Dakle, "aktivan" lotos je onaj koji još uvek fizički stoji na tabli kao 40 i nije uklonjen iz `LotusPositions`.

2. **Šta radi isecak `0x5da4588 - 0x5da47f4` (`c_lotus_hit.txt`):**
   **Kritično otkriće:** Ovaj isecak **NE proverava Lotos (`0x28 = 40`)**, već proverava `ldrb w8, [x0, #0x12]; cmp w8, #0x17` (**23**) `[KOD: 0x5da45e4-0x5da45e8]`!
   - U toj grani za `SlotValue == 23` (drugačiji dvoslojni/dvobojni element, gde su `+0x10` i `+0x11` boje):
     - Ako je `slot+0x10` važeća boja (`x28.Contains`) I (`slot+0x11 == 1` ili važeća boja) -> pretvara ga u `SlotModel::ToSpecial(slot, 0, 1, 0, 0)` `[KOD: 0x5da46ac]` (specijal, bez rupe i bez RNG-a!).
     - Ako je samo `slot+0x10` važeća boja -> `SlotModel::ToColor(slot, slot+0x11, false)` `[KOD: 0x5da4744]`.
     - Ako je samo `slot+0x11` važeća boja -> `SlotModel::ToColor(slot, slot+0x10, false)` `[KOD: 0x5da47dc]`.
   - Ta petlja **ne** ubacuje polje u rušenje i **ne** troši RNG.
   - **Zašto igra uklanja pravi Lotos (`SlotValue == 0x28 = 40`) kad ga pogodi eksplozija:** Pravi Lotos ima `SlotValue = 40` i postavljen je sa `slot+0x18 |= 1` i `slot+0x24 = 0` `[KOD: 0x5ec54ac-0x5ec54bc]`. Njegovo uklanjanje u eksploziji mora biti ili u **ranijem delu** `BoardAnalyzer::GetAreaOfEffectDestructionSlots` (pre `0x5da4580`), ili u `GameLogic::DestroyMatches` / `SlotModel` / `FroggyFu::RevertLotuses` / pasivu. Ovaj isecak to ne sadrži, pa treba poslati ceo `GetAreaOfEffectDestructionSlots` i `RevertLotuses`.
